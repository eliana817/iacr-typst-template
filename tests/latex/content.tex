\section*{Introduction}

This document is a guide to using the \texttt{iacrj} document template for three IACR journals:
\begin{itemize}
\item IACR Transactions on Symmetric Cryptology (ToSC),
\item IACR Transactions on Cryptographic Hardware and Embedded Systems (TCHES),
\item IACR Communications in Cryptology (CiC)
\end{itemize}
The \texttt{iacrj} template is intended to be the Typst equivalent for the \texttt{iacrj} document class in LaTeX.

The class is still in development and feedback and comments are welcome.
The latest version can be found at \href{https://github.com/eliana817/iacr-typst-template/}{\texttt{https://github.com/eliana817/iacr-typst-template/}}.
There is also a \href{https://github.com/IACR/latex}{github repository} where you can open issues or to submit pull requests.

\paragraph*{NOTES}
\begin{itemize}
\item The production system to which you submit your final version does not yet support Typst.
\item The default fonts are provided by the template.
      Please do not change this.
\item Avoid using too many packages.
\item Don't try to change the bibliography style, the page style, or the page numbering.
\end{itemize}
